WSO2 API Manager Backstage Plugin API Collection (1.0.0)

Download OpenAPI specification:

Internal Backstage backend API exposed by the wso2-api-platform-backend plugin. The frontend wso2-api-platform plugin consumes these endpoints. Direct OpenAPI YAML: wso2-api-platform-backend.yaml Postman collection: wso2-api-platform-backend.postman_collection.json

Health

Catalog

Request a catalog refresh

Authorizations:
Wso2AccessTokenAuthNone
header Parameters
X-WSO2-Access-Token
string

Optional WSO2 access token. If omitted, the backend may use the configured service account token.

Responses

Local Backstage backend URL from BACKEND_BASE_URL plus the WSO2 API Manager plugin route.

http://localhost:7007/api/wso2-api-platform/refresh

Relative Backstage discovery base URL for the WSO2 API Manager backend plugin.

/api/wso2-api-platform/refresh

Request samples

  • Refresh catalog
curl -X POST 'http://localhost:7007/api/wso2-api-platform/refresh' \
  -H "X-WSO2-Access-Token: $WSO2_ACCESS_TOKEN"

Response samples

  • 200
  • 500
Content type
application/json
{
  • "message": "Catalog refresh triggered. This may take a few moments to reflect in the catalog."
}

Generate an API key

Authorizations:
Wso2AccessTokenAuthNone
path Parameters
apiId
required
string
header Parameters
X-WSO2-Access-Token
string

Optional WSO2 access token. If omitted, the backend may use the configured service account token.

Request Body schema: application/json
optional
keyName
string
keyType
string
Default: "PRODUCTION"
Enum: "PRODUCTION" "SANDBOX"
validityPeriod
integer

Validity period in seconds. Use -1 for keys that never expire.

object

Responses

Local Backstage backend URL from BACKEND_BASE_URL plus the WSO2 API Manager plugin route.

http://localhost:7007/api/wso2-api-platform/apis/{apiId}/generate-key
